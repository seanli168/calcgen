Teoría del Color Básica: Entendiendo HEX, RGB y HSL

Publicado: Enero 2026 • Por CalcGen

Cada color en una pantalla se define por un código. Entender HEX, RGB y HSL te da control total sobre tus diseños. Esta guía cubre los tres formatos principales.

Códigos HEX

Los códigos HEX son números de 6 dígitos como #2563EB. Cada par representa rojo, verde y azul en hexadecimal. #FF0000 = rojo puro, #00FF00 = verde puro, #0000FF = azul puro.

Consejo: Usa nuestro selector de color para obtener valores HEX, RGB y HSL al instante.

RGB

RGB usa tres números de 0-255: rgb(37, 99, 235). Mismo concepto que HEX, diferente notación. Útil en CSS y software de diseño.

HSL

HSL = Tono (0-360°), Saturación (0-100%), Luminosidad (0-100%). hsl(221, 83%, 53%). Más intuitivo para diseñadores.
