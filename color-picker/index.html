Frequently Asked Questions

What is a HEX color code?
A 6-digit code like #2563EB. Used in HTML/CSS for web colors.
RGB vs HSL?
RGB uses Red/Green/Blue values. HSL uses Hue/Saturation/Lightness — often easier for design.
